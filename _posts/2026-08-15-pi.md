# Pi for Typora

Pi is a theme pair (light and dark) that faithfully recreates the visual style of [pi.dev/docs/latest](https://pi.dev/docs/latest). Design tokens were extracted directly from the site's own stylesheet, so colors, typography, and borders match the original documentation closely.

> Designed and tested on Windows. Should work on macOS/Linux as well.

## Features

- **Light & dark variants** — `Pi` and `Pi Dark` share the same typography and component rules.
- **Serif typography** — headings and body use Plantin-style serif (`Plantin MT Pro` → `Georgia` fallback).
- **Grid-paper texture** — the signature faint blueprint grid behind the page.
- **Steel-blue accent** — `#6a9fcc` on dark, thread-blue `#4b607c` on light.
- **Mono code** — `Commit Mono` / `Departure Mono` (falls back to Consolas / ui-monospace).
- **Squared, bordered boxes** — code blocks, tables, quotes, and images use flat 1px borders with no border radius.
- **Accurate code editing** — CodeMirror caret and active-line are styled, and `.md-fences` keeps CodeMirror's internal line measurement intact for precise click-to-caret.

## Installation

1. Download and unzip `pi-theme.zip`.
2. Open **Typora → Settings → Appearance → Open Theme Folder**.
3. Copy `pi.css` and `pi-dark.css` into the theme folder.
4. Restart Typora, then select **Pi** from the Themes menu. Use the light/dark toggle to switch variants.

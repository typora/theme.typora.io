# danya for Typora

A calm, low-saturation teal theme focused on clean, paper-like reading.

## Features

- Low-saturation teal accent, restrained and unflashy
- Sans headings, serif body, Times for Latin text and digits
- Centered three-line tables
- Nested blockquotes deepen step by step
- Teal-tinted raised code block; line numbers via Typora's own setting
- GitHub-style alerts (Typora ≥ 1.8, enable "GitHub Style Alert")

## Customization

Colors, fonts, sizes and spacing live in `danya/variables.css`; save and re-select the theme to apply.

## Installation

One-line (Windows, PowerShell):

```powershell
irm https://raw.githubusercontent.com/liuzl621/danya-typora-theme/main/install.ps1 | iex
```

Or manually: download the release zip, copy `danya.css`, `danya.user.css` and the `danya/` folder into Typora's theme directory, restart and select **danya**.

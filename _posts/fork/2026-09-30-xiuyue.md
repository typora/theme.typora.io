# Xiuyue (秀月)

Xiuyue is a customized setup based on the [Sonnet theme](https://theme.typora.io/theme/Sonnet/). It includes separate dark and light themes, Catppuccin file icons, Markdown and code block styling, and a Linux installer that backs up existing Typora settings.

## Install

Download the [repository](https://github.com/Wang-Yang-source/typora-xiuyue-config), then copy the contents of its `themes/` directory to Typora's theme folder. Restart Typora and select **Xiuyue Dark** or **Xiuyue Light** from the Themes menu.

On Linux, you can also run `./install.sh` after closing Typora. This applies the portable editor preferences and creates a local backup. The script and configuration were tested with Typora 1.14.9 on Linux. Windows and macOS users can install the theme files manually; those platforms have not been tested.

The theme is derived from [Sonnet](https://github.com/bexino/sonnet). Third-party credits and licenses are listed in the [repository](https://github.com/Wang-Yang-source/typora-xiuyue-config/blob/main/THIRD_PARTY.md).

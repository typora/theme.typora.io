> 一套为 Typora 打造的霓虹动画主题全家桶，6 款风格覆盖暗色与亮色场景。

Aurora Themes 包含 6 个精心设计的主题，每个主题都带有独特的霓虹动画效果，为你的 Markdown 编辑体验增添视觉魅力。

## 主题一览

| 主题名称 | CSS 文件 | 风格 | 色调 |
|----------|----------|------|------|
| Aurora Matrix | `aurora-matrix.css` | 赛博朋克 / 霓虹光效 | 暗色绿 |
| Aurora Nebula | `aurora-nebula.css` | 宇宙深空 / 星云紫光 | 暗色紫 |
| Aurora Ember | `aurora-ember.css` | 熔岩暗夜 / 烈焰燃烧 | 暗色红 |
| Aurora Frost | `aurora-frost.css` | 极地冰川 / 冰霜之蓝 | 暗色蓝 |
| Aurora Sakura | `aurora-sakura.css` | 樱花飞舞 / 可爱清新 | 亮色粉 |
| Aurora Sunset | `aurora-sunset.css` | 落日余晖 / 温暖治愈 | 亮色橙 |

## 特性

- **12+ 动画效果**：H1 流光扫过下划线、H2 霓虹灯条呼吸、H3 菱形旋转装饰、代码块扫描灯条、呼吸灯、Shimmer 光扫等
- **暗色 4 款 + 亮色 2 款**：覆盖全天候使用场景
- **单文件架构**：每个主题仅一个 CSS 文件，零依赖，即装即用
- **兼容 Typora 1.12+**：支持最新版本

## 安装方法

1. 下载 `Aurora-Themes-Pack-6in1.zip` 并解压
2. 将所有 `.css` 文件复制到 Typora 主题目录：
   - **Windows**: `C:\Users\<用户名>\AppData\Roaming\Typora\themes\`
   - **macOS**: `~/Library/Application Support/typora/themes/`
   - **Linux**: `~/.config/Typora/themes/`
3. 重启 Typora，在菜单 `主题` 中选择对应主题

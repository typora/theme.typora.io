YOUNG is a pair of quiet light and dark themes for Chinese and English writing. Soft grayscale colors, Chinese text matching the YOUNG website, Courier New Latin text, and a narrow column keep the page simple.

## Features

- Matching Young Light and Young Dark variants.
- 15px body text, 1.5 line height, and a 680px writing column.
- Bundled Adobe Source Han Serif SC ExtraLight Chinese font, matching the website source and weight (250), with full character coverage under SIL OFL 1.1. Courier New for Latin text.
- Coordinated tables, code, sidebar, selection, and print styles.
- Consistent sidebar fonts and two-line file summaries.

## Installation

Download and unzip the theme. In Typora, open **Preferences → Appearance → Open Theme Folder**. Copy `young-light.css`, `young-dark.css`, and the entire `young-fonts` directory into it. Restart Typora, then select **Young Light** or **Young Dark**.

The font folder is required. Chinese uses Source Han Serif SC ExtraLight, not MingLiU. Courier New is a system font and is not redistributed.

Developed on macOS. Chinese font source and weight match the YOUNG website; the bundled full font is used instead of its web subset. Windows and Linux have not been tested; no specific Windows unibody styling is included. Native macOS window-title fonts are not controlled by theme CSS.

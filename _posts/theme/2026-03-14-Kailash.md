# Kailash Theme for Typora | 冈仁波齐主题

一款为藏文优化的高级古籍风格 Typora 主题，灵感源自神圣的冈仁波齐峰。

## 设计特点 | Features

- **神圣灵感**: 灵感源自冈仁波齐峰，融合藏传佛教艺术与现代极简主义
- **高级配色**: 参考《四库全书》《永乐大典》等顶级古籍配色方案
- **专用字体**: 使用 Qomolangma-UchenSarchung 藏文字体
- **优雅行距**: 行距 1.8，藏文 2.0，营造舒适的古籍阅读体验
- **不加粗标题**: 标题依靠字号和颜色层次区分，呈现纯粹的古籍排版风格
- **混合排版**: 完美支持藏文、中文、西文混排

## 安装方法 | Installation

### 1. 复制主题文件

将 `kailash.css` 复制到 Typora 主题目录：

| 操作系统    | 主题目录路径                                              |
| ----------- | --------------------------------------------------------- |
| **macOS**   | `~/Library/Application Support/abnerworks.Typora/themes/` |
| **Windows** | `%APPDATA%\Typora\themes\`                                |
| **Linux**   | `~/.config/Typora/themes/`                                |

```bash
# macOS 一键安装
./install-kailash.sh

# 或手动复制
cp kailash.css ~/Library/Application\ Support/abnerworks.Typora/themes/
```

### 2. 确认字体路径

主题中使用的字体路径为：

```
/Users/khangey/Desktop/chrome-mv3/fonts/Qomolangma-UchenSarchung.ttf
```

如果字体位置不同，请编辑 `tibetan-classic.css` 文件，修改 `@font-face` 中的 `url` 路径。

### 3. 重启 Typora

重启后在 `主题` 菜单中选择 `Tibetan-Classic` 或 `藏典`。

## 自定义修改

### 修改字体路径

编辑 `kailash.css` 第 17-24 行：

```css
@font-face {
    font-family: 'Qomolangma Uchen Sarchung';
    src: local('Qomolangma-UchenSarchung'),
         url('你的字体路径/Qomolangma-UchenSarchung.ttf') format('truetype');
```

### 修改配色

编辑 CSS 变量部分：

```css
:root {
    --classic-paper: #F7F4ED;
    --classic-paper-light: #FDFBF7;
    --ink-primary: #2C3E50;
    --cinnabar: #B54A3F;
    /* ... */
}
```

### 修改行距

编辑 CSS 变量：

```css
--line-height-body: 1.8;  /* 修改为你需要的值 */
```

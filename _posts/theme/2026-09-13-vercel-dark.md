# Vercel Dark

Vercel Dark brings Vercel's clean document style to Typora with a black canvas, layered dark surfaces, restrained borders, and crisp typography for low-light writing.

It preserves the original Vercel theme's Geist typeface, Inter italic variant, and LXGW WenKai support for Chinese text while extending the palette across Typora's editor and application chrome.

## Features

- **Complete dark interface** — the editor, sidebar, file tree, outline, menus, dialogs, search, preferences, notifications, and scrollbars share one cohesive palette.
- **Readable document styling** — headings, links, blockquotes, tables, task lists, footnotes, math, and horizontal rules are tuned for clear hierarchy on dark surfaces.
- **Dark code experience** — inline code, fenced code blocks, source mode, and syntax highlighting use layered backgrounds and accessible colors.
- **Responsive writing layout** — the document column and spacing adapt for narrower Typora windows.
- **Print-safe output** — print styles return documents to a white page with dark text and simplified decoration.
- **Bundled typography** — Geist, Inter Italic, and LXGW WenKai fonts are included with the theme.

## Installation

1. Download and extract [Vercel Dark](https://github.com/euanchua/typora-vercel-dark-theme/releases/download/v1.0.0/typora-vercel-dark-theme-v1.0.0.zip).
2. In Typora, open **Settings/Preferences → Appearance → Open Theme Folder**.
3. Copy `vercel-dark.css` and the complete `vercel/` resource folder into the theme folder.
4. Restart Typora and select **Vercel Dark** from the **Themes** menu.

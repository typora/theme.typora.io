# Neon Rio

A cyberpunk arcade dark theme: near-black with a subtle HUD grid, neon-yellow accents and cyan details.

![Neon Rio theme in Typora](/media/theme/neon-rio/neon-rio.png)

## Highlights

- **HUD grid** over a near-black background (`#0a0b10`).
- **Two lights only:** neon yellow (`#f8e602`) and cyan (`#00e5ff`).
- **Numbered sections:** every H2 gets a counter (01 /, 02 /, 03 /).
- **Light condensed headings** in Avenir Next Condensed, with labels and code in SF Mono.
- **Diagonal cut corner** on code blocks and the front matter block.
- **One moving part:** only the ▶ marker of the open file in the sidebar pulses.
- **Print-friendly:** printing and PDF export switch to light colors.

## Installation

1. Download the theme and unzip it.
2. In Typora, open **Preferences → Appearance → Open Theme Folder**.
3. Copy `neon-rio.css` into that folder.
4. Restart Typora and choose **Themes → Neon Rio**.

## Notes

> Designed and tested on macOS (Typora 1.14). Not fully tested, but should work on Windows and Linux. This theme does not include styles for the Windows "unibody" window style.

Fonts: Avenir Next Condensed for headings, Inter for body text (falls back to the system font) and SF Mono for labels and code.

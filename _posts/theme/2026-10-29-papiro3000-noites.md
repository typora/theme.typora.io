# Papiro3000 Noites

Ancient Egypt meets the 2000s, for late-night writing. A papyrus sheet lit as if by an oil lamp rests on dark basalt dusted with gold. *Noites* is Portuguese for "nights".

![Papiro3000 Noites theme in Typora](/media/theme/papiro3000-noites/papiro3000-noites.jpg)

## Highlights

- **Papyrus sheet** with crossed fibers and darker edges, on a basalt background with gold dust.
- **Lapis-blue Copperplate headings**, with a holographic rule (gold, turquoise and lapis) under H1.
- **Egyptian details:** the Eye of Horus before each H2, a pharaoh's cartouche around blockquotes and an ankh between two stars on horizontal rules.
- **2000s details:** Aqua-style round checkboxes, frosted-glass code blocks, glossy table headers, Lucida Grande and Monaco.
- **Dark sidebar** that matches the basalt background.
- **Print-friendly:** print styles use a plain white page, without the basalt background or the papyrus texture.

## Installation

1. Download the theme and unzip it.
2. In Typora, open **Preferences → Appearance → Open Theme Folder**.
3. Copy `papiro3000-noites.css` into that folder.
4. Restart Typora and choose **Themes → Papiro3000 Noites**.

## Notes

> Designed and tested on macOS (Typora 1.14). Not fully tested, but should work on Windows and Linux, with fonts falling back to other system fonts. This theme does not include styles for the Windows "unibody" window style.

Fonts: Skia, Copperplate, Lucida Grande, Monaco and Noto Sans Egyptian Hieroglyphs (macOS). On Windows the hieroglyphs use Segoe UI Historic.

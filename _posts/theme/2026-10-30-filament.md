# Filament for Typora

A theme family inspired by the [Laravel](https://laravel.com) ecosystem: **Filament PHP**,
**Livewire** and Laravel itself. Six independent CSS files, one for every combination of
light/dark mode and accent colour.

| Theme | Mode | Accent |
|---|---|---|
| `filament-light.css` | Light | Amber |
| `filament-dark.css` | Dark | Zinc + Amber |
| `filament-light-red.css` | Light | Scarlet (Laravel) |
| `filament-dark-red.css` | Dark | Scarlet + Obsidian |
| `filament-light-pink.css` | Light | Rose (Livewire) |
| `filament-dark-pink.css` | Dark | Rose + Slate |

## Features

- **Six variants** built on the same structure, so switching accent or mode never changes the layout
- **Zero external dependencies** — Inter and JetBrains Mono are bundled as WOFF2 and load offline; PDF export keeps the typography
- **Filament-style components** — card code fences with a language badge, admin data tables with uppercase headers, alert callouts and status badges
- **Complete element coverage** — headings, lists, task lists, blockquotes, GitHub-style alerts, tables, footnotes, table of contents, inline math, keyboard keys, images
- **Complete application chrome** — sidebar, file tree, outline, megamenu, context menus, quick open, dialogs, preferences, autocomplete and notifications follow the theme (no white panels in dark mode)
- **Source code mode** — CodeMirror tokens, gutters, cursor and selection are themed for `.cm-s-typora-default`
- **Print / PDF** — exact colour reproduction, no background texture or shadows, no blocks split across pages
- **Responsive** — the writing area adapts on narrow windows and wide tables scroll instead of overflowing

## Installation

1. Download and unzip the repository.
2. Open Typora → **File → Preferences → Appearance → Open Theme Folder**.
3. Copy the `filament-*.css` files **and the `fonts/` folder** into that folder.
4. Restart Typora and pick a theme from the **Themes** menu.

The theme name shown by Typora comes from the file name: `filament-dark.css` appears as
**Filament Dark**. The fonts are loaded with a relative path, so `fonts/` must stay next to the CSS
files; without it the theme falls back to system fonts and still works.

## Compatibility

Designed and tested with **Typora 1.14.9 on Linux**. It should work on Windows and macOS, but the
Windows "unibody" window frame and the macOS seamless title bar have not been fully tested; the
theme does not include platform-specific window frame styles.

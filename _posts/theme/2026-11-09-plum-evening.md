# Plum Evening

A soft reading theme with plum headings on a warm ivory background. Tables, quotes and code blocks use the same palette, and text colours meet WCAG AA contrast on the background.

## Install

Download the theme from the [repository](https://github.com/ello-lithuania/typora-steadfast-themes), copy `plum-evening.css` to your Typora theme folder (Preferences > Appearance > Open Theme Folder), restart Typora and choose **Plum Evening** in the Themes menu.

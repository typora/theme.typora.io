# Annal (卷帙)

**Annal** is a wide-screen academic and editorial theme for Typora, available in both **Light (`Annal`)** and **Dark (`Annal Dark`)** variants. It pairs clean GitHub-style Markdown hierarchy with classic Chinese scholarly typography and warm pine-soot ink palettes for comfortable long-form writing and research drafts.

![Annal Light](https://raw.githubusercontent.com/xbbwww/typora-theme-annal/main/screenshots/annal-light.png)

![Annal Dark](https://raw.githubusercontent.com/xbbwww/typora-theme-annal/main/screenshots/annal-dark.png)

## Highlights

- **Wide & Effortless Reading** — `1200px` wide reading measure paired with a comfortable `20px` base font size, designed to reduce eye strain during long academic writing sessions.
- **Dual Palettes (Light & Dark)**
  - **Annal (Light)**: Crisp white paper with ink-black text and classic cinnabar-red (`#d40000`) editorial accents.
  - **Annal Dark**: Soothing warm pine-soot ink canvas (`#1d1c1a`) with soft paper-grey text (`#ddd8ce`), avoiding harsh pure-black contrast.
- **Scholarly Mixed CJK + Latin Typography** — `Times New Roman` for Latin & numerals, paired with automatic Chinese semantic fallbacks (Song / Hei / Kai / FangSong) for headings, blockquotes, emphasis, and body text.
- **Polished Details** — Full dark syntax highlighting for code fences, dark Mermaid diagrams, compact cinnabar footnote badges, and seamless full-bleed PDF export on macOS without dark/white border seams.
- **Zero Bundled Commercial Fonts** — Pure single-file stylesheets (`annal.css` & `annal-dark.css`) using native system & open-source font fallbacks out of the box.

## Compatibility

> Designed and tested on macOS. Not fully tested on Windows/Linux, though standard system font fallbacks for Windows (`SimHei`, `FangSong`, `KaiTi`, `Microsoft YaHei`, `Consolas`) are included. Does not include custom styles for Windows "unibody" mode.

## Installation

1. Download the [ZIP archive](https://github.com/xbbwww/typora-theme-annal/archive/refs/heads/main.zip) from GitHub and extract it.
2. In Typora, open **Preferences → Appearance → Open Theme Folder**.
3. Copy `annal.css` and `annal-dark.css` into the `themes` folder.
4. Restart Typora and choose **Annal** or **Annal Dark** from the **Themes** menu.

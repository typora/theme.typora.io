# Ayu Dark

Ayu Dark is a dark Typora theme built on the [Ayu](https://github.com/ayu-theme) color palette. It pairs the signature Ayu Dark background and foreground with the canonical Ayu syntax colors, and themes the full macOS interface — editor, code blocks, and app chrome all feel like one cohesive whole.

## Highlights

- **Faithful Ayu Dark palette:** background `#0A0E14`, foreground `#E6E6E6`, signature blue accent `#39BAE6`.
- **Rainbow headings:** h1–h6 each carry their own Ayu color (blue, yellow, green, teal, red, purple).
- **Full syntax highlighting** in fenced code blocks and source mode, using the canonical Ayu syntax palette.
- **Complete macOS chrome:** sidebar, quick open, megamenu, preferences, search panel, and focus mode are all themed, not just the write area.
- **Styled markdown elements:** striped tables, blockquotes with a blue accent border, task-list checkboxes with a filled checked state, footnotes, TOC, YAML front matter, math, and GitHub-style alerts.
- **PDF-friendly export:** print rules flip to a light background with dark text so exported documents stay readable.

Designed and tested on macOS. Not fully tested, but should work for Windows/Linux. This theme does not include styles for Windows "unibody" style.

# Gemini Theme for Typora

A clean, modern Typora theme inspired by the Google Gemini web interface and Material Design 3.

## Features
- **Material Design 3**: Clean sans-serif typography prioritizing Google Sans, Outfit, and Inter.
- **Generative UI Inspired Cards**: Code blocks and blockquotes are rendered as soft, borderless, rounded cards.
- **Airy Tables**: Clean table styles with custom padding to ensure content is easy to read.
- **Dual Mode**: Fully styled dark and light themes (gemini.css and gemini-dark.css).

## Installation
1. Download this theme.
2. Open Typora Preferences -> Appearance -> Open Theme Folder.
3. Copy gemini.css and gemini-dark.css to the theme folder.
4. Restart Typora and select "Gemini" or "Gemini Dark".

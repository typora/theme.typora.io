# Legible

Legible is a high-contrast theme in light and dark, set in B612, the typeface Airbus
commissioned for cockpit screens, with Lato headings. Every letter of B612 keeps its basic
shape yet looks as unlike the others as possible, so none can be mistaken for another.

[See it live](https://baw-dev.github.io/legible-typora-theme/): the sample page, exported from
Typora, with a switch for Legible Dark.

## Highlights

- **Accessible:** every text colour meets WCAG 2.2 AAA contrast (7:1), and borders and focus
  rings meet 3:1, in both light and dark.
- **Room for code:** code blocks fit 80 columns, and 100 or 120 in wider windows. Box-drawing
  and block characters stay on the grid.
- **Print-ready:** PDFs print on white, with 80-column code on A4 and Letter, from either theme.
- **Nothing else to install:** all eight B612 styles and three Lato weights come with the theme.

## Installation

1. Download and unzip [Legible](https://github.com/baw-dev/legible-typora-theme/archive/refs/heads/main.zip).
2. In Typora, choose **Preferences › Appearance › Open Theme Folder**.
3. Copy `legible.css`, `legible-dark.css` and the `legible` folder there.
4. Restart Typora, then choose **Themes › Legible** or **Legible Dark**.

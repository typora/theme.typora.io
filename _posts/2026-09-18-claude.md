# Claude Theme for Typora

A warm, considered writing theme inspired by Anthropic's Claude design language. Available in two modes: **Claude** (light) and **Claude Dark**.

## Features

- **Warm canvas** — cream base `#faf9f5` in light mode, layered warm darks `#262624 / #1f1e1d / #141413` in dark mode. No cool gray, no pure white.
- **Terracotta coral accent** — `#d97757`, used sparingly for links, quotes, and highlights.
- **Editorial typography** — serif prose (Georgia with Times fallback) and serif display headings (Cormorant Garamond), paired with CJK-friendly fallbacks (PingFang SC, Microsoft YaHei, Noto Sans CJK).
- **Restrained syntax highlighting** — muted corals, warm browns, and grays, covering CodeMirror, Pygments, and GitHub Primer token sets for full compatibility.
- **Themed sidebar & UI chrome** — file tree, outline, and controls follow the same warm palette.

## Installation

1. Download and unzip the theme.
2. Copy `claude.css` and `claude-dark.css` into Typora's theme folder.
3. Restart Typora and select **Claude** or **Claude Dark** from the Themes menu.

## Claude Like

A Typora theme capturing Claude AI's signature warm aesthetic.

![Claude Like](claude-like.png)

### Features
- **Dual-script fonts**: Anthropic Serif (Latin) + Noto Serif SC (CJK), proper `unicode-range` isolation
- **120+ CSS variables**: semantic tokens for colors, spacing, and layout
- **Mermaid diagrams**: Claude-color theming with grid canvas and zoom
- **GFM Alerts**: 5 colors (NOTE/TIP/IMPORTANT/WARNING/CAUTION)
- **Card grid & badge wall** for rich HTML layouts
- **Print/PDF**: fully preserved on export

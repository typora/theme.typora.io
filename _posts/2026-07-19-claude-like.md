## Claude Like

A meticulously-crafted Typora theme capturing Claude AI's signature warm aesthetic — **40 iterations** across every Markdown element.

### What Makes It Different
- **Dual-script fonts**: Anthropic Serif (Latin) + Noto Serif SC (CJK) + Anthropic Mono (code) with proper `unicode-range` isolation
- **120+ CSS variables**: semantic layering with proportional rhythm tokens
- **6-level nesting**: blockquotes, lists, and details scale down gracefully
- **Mermaid diagrams**: grid canvas, zoom, Claude-color theming, v11.13+ compatible
- **GFM Alerts**: 5 semantic colors (NOTE/TIP/IMPORTANT/WARNING/CAUTION) with nested content support
- **Three skins**: Light (`#faf9f5` cream paper), Dark (`#1a1917`), Grey (`#3f454c`)
- **Print/PDF**: fully preserved on export

### Features
- Warm cream-paper reading background with terracotta coral accent (`#d97757`)
- HTML definition list (`dl`/`dt`/`dd`) card styling
- Card grid layout (multi-column without plugins)
- Badge wall for centered image galleries
- Diff/ins/del coloring for changelogs
- Custom coral checkbox task lists
- Diagrams with Claude-theme color palette

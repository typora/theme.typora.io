# Sprinkles for Typora

An emoji-flavored minimal theme. Every heading and link carries its own emoji prefix, while code blocks use a dark Dracula palette with macOS traffic-light dots.

## Features

- **Emoji headings** — H1–H6 each get a distinct emoji prefix
- **Emoji links** — links carry a rainbow emoji prefix and change color on hover
- **Dark code fences** — Dracula-style syntax highlighting with the macOS traffic-light dots
- **Green inline code & highlight** — dark background with green text
- **Rounded images** — images get rounded corners and a soft shadow
- **Custom fonts** — JetBrains Mono for body, Hack for code

## Installation

1. Download and unzip the theme.
2. Copy `sprinkles.css` and the `sprinkles/` folder into Typora's theme folder.
3. Restart Typora and select **Sprinkles** from the Themes menu.

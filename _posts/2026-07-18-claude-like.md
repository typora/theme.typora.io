# Claude Like Theme for Typora

A meticulously-crafted Typora theme capturing Claude AI's signature warm aesthetic — **38 iterations** of refinement across every Markdown element.

## What Makes It Different

Unlike other "Claude-like" themes that only recolor a few elements, this theme is a **full Markdown design system**:

| Feature | Other Claude Themes | Claude Like |
|---------|---------------------|-------------|
| Font system | One font | **Dual-script**: Serif (prose) + Sans (UI) + Mono (code) |
| Color depth | 3-5 variables | **50+ CSS variables** with semantic layering |
| Nesting support | Basic | **6-level** blockquotes + **6-level** lists with proportional rhythm |
| Mermaid | None/broken | **Full support**: grid canvas, zoom, Claude-color theming, v11.13 tested |
| GFM Alerts | Missing | **5 semantic colors** with nested content support |
| Skins | Light only | **Light + Dark + Grey** |
| Print/PDF | Untested | **Fully covered**: tables, diagrams, TOC preserved in export |
| QA coverage | Untested | Validated against 60+ nested Markdown combinations |

## Installation
1. Download **claude-like-v1.0.zip** from the [Release page](https://github.com/WJH-makers/typora-theme-claude-like/releases)
2. Typora → Preferences → Appearance → Open Theme Folder
3. Extract everything (CSS files + `claude_fonts/`) into the theme folder
4. Completely quit and restart Typora
5. Select **Claude Like** / **Claude Like Dark** / **Claude Like Grey**

## Design Philosophy
- **Content first**: Serif body text for reading comfort, sans-serif for UI clarity
- **Coral warmth**: `#d97757` accent on `#faf9f5` cream — like writing on warm paper
- **Proportional rhythm**: Nested elements scale down gracefully rather than breaking
- **No rainbow sidebar**: Clean monochrome structure with color reserved for semantics

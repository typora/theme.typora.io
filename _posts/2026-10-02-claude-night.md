# Claude Night for Typora

Claude Night is a warm, low-glare dark theme for long-form writing. It pairs a charcoal canvas and soft ivory text with terracotta accents and a serif reading face.

## Features

- Georgia and Cambria serif typography, with system fallbacks for Chinese text.
- A warm charcoal palette with carefully contrasted headings, links, and blockquotes.
- Distinct syntax colors for code fences.
- Coordinated styling for tables, YAML front matter, and math block editing.
- No bundled fonts or external runtime assets.

## Installation

1. Download the theme archive and extract `claude-night.css`.
2. In Typora, open **Preferences → Appearance → Open Theme Folder**.
3. Copy `claude-night.css` into the theme folder.
4. Restart Typora and select **Claude Night** from the **Themes** menu.

Designed on Typora for Windows. Other platforms have not been separately visually tested.

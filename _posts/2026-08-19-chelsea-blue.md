# Chelsea Blue

A blue-forward Typora theme inspired by Chelsea blue, with a Sakurajima Mai
background and a translucent writing surface.

## Features

- Chelsea blue accents for headings, links, borders, inline code, and selection.
- High-contrast dark code blocks with distinct syntax colors.
- Readable translucent writing surface over the bundled background illustration.

## Installation

1. Download and unzip this theme from the [GitHub repository](https://github.com/PJMa192/Chelsea-blue).
2. Open Typora **Settings/Preferences -> Appearance -> Open Theme Folder**.
3. Copy `chelsea-blue.css` and the `chelsea-blue` asset folder into the theme folder.
4. Restart Typora and select **Chelsea Blue** from the Themes menu.
